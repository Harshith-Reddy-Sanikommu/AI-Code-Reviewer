# 💻 AI Code Reviewer

An AI-powered application that reviews source code using Google's Gemini API.

## Features

- Supports:
  - Java
  - Python
  - C++
  - C
  - JavaScript

- Upload source code files
- Paste code directly
- AI code explanation
- Bug detection
- Improvement suggestions
- Time complexity analysis
- Space complexity analysis
- Optimized code generation
- Syntax highlighting

## Tech Stack

- Python
- Streamlit
- Gemini API
